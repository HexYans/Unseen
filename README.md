# Unseen

**截图这件事，最好让你感觉不到它存在。**

macOS 截图 · 长截图 · 录屏 · 剪贴板历史
原生 Swift 实现，液态玻璃界面。

<sub>作者 Hex Yans · macOS 14+ · 通用二进制</sub>

## 为什么是 Unseen

大多数截图工具的交互是这样的：

> 按下快捷键 → 屏幕黑掉 → 拖一个框 → 弹出工具栏 → 选保存位置 → 确认 → 终于完事

每一步都在提醒你「你在用一个工具」。

Unseen 想做的是反过来的事 —— **你按下快捷键，剩下的就已经走完，然后忘掉它**。

- **不需要想**：即时模式零交互，按下快捷键就已经截好，同时保留交互模式，感受优雅体验
- **不需要等**：原生渲染，没有 Electron 带来的启动延迟，如沐春风
- **不需要找**：剪贴板历史就在同一个快捷键体系里，复制过的东西不会丢

界面用 macOS 26 的液态玻璃材质。不是贴一层毛玻璃图片，是真的让桌面从窗口里透出来 —— 效率与优雅从来不是反义词

## 功能

### 截图

五种类型，在一个快捷键体系里。

| 模式 | 说明 |
|---|---|
| **区域截图** | 拖拽框选。鼠标附近自动放大预览，逐像素微调 |
| **即时截图** | 零交互：按下快捷键自动截图，无感，高效 |
| **窗口截图** | 悬停高亮，单击选中，回车确认 |
| **全屏截图** | 不弹覆盖层，直接取鼠标所在屏幕 |
| **长截图** | 滚动拼接，实时预览，无感拼接 |

选区外压暗、选区内清晰。可调节的窗口圆角，贴到任何背景上都像一扇真的窗口。

### 长截图

悬浮预览窗口，**实时预览拼接长图**，截到多少一目了然。

- 手动滚动，也能自动滚动
- 停多久都不会自己结束；想停就点停止
- 结束之后想接着截，点「继续」，截图内容不会丢
- 只接受向下滚动的新内容，回看不会拼进重复段落

### 录屏

选择一块区域，亦或是全屏录制，只需要单击回车回车，便开始录制。选区边框和计时方便您的使用，**而这些东西不会出现在视频里**。

### 剪贴板

后台常驻，自动收集复制过的文本、图片、文件。

```
⌘P    唤出历史面板（在鼠标位置弹出，不用找）
1–9   复制第 N 条
⌘1–9  自动返回原App并填充所选内容，更快捷，更省心
空格   快速预览
```

有搜索、有分类、有钉图。图片预览的背景和 App 本身一致，不是一块突兀的黑板。

### 标注

截图后直接画：箭头、矩形、椭圆、直线、铅笔、荧光笔、马赛克、文字、序号、便签、贴纸。

### 还有

OCR 识别文字 · 取色 · 按键显示（录教程用）· 套壳美化等实用功能。

## 安装

**要求**：macOS 14.0 或更高，Apple Silicon / Intel 均可。

1. 下载 `Unseen-<版本>.dmg`
2. 拖进「应用程序」
3. 首次打开若被系统拦下：
   **系统设置 → 隐私与安全性 → 滚到底 → 「仍要打开」**

> 本 App 使用开发证书签名，**未做 Apple 公证**。这不是病毒，只是没有付费公证。

### 首次运行需要两个权限

| 权限 | 用途 |
|---|---|
| **屏幕录制** | 截图 / 录屏必需。不授权会得到黑屏 |
| **辅助功能** | `⌘1–9` 直接粘贴、自动粘贴等需要模拟键盘的功能 |

授权后需要**退出 App 再重新打开**才生效。

## 快捷键

装好即有默认值，全部可以在 设置 → 快捷键 里改。共 30 项可绑定，含 12 个标注工具。

| 动作 | 默认 |
|---|---|
| 打开面板 | ⌘P |
| 钉图 | ⇧⌘P |
| 区域截图 | ⌥A |
| 窗口截图 | ⌥Q |
| 全屏截图 | ⌥W |
| 长截图 | ⌥Z |
| 即时窗口 | ⌥S |
| 即时全屏 | ⌥D |
| 录屏 | ⌥X |

OCR / 取色 / 按键显示 / 套壳 等工具默认留空，为您的定制化体验预留空间。

**想留空**：点键位开始录制后按 <kbd>Delete</kbd>，或右键选择「清除快捷键」。

## 一些设计上的取舍

写给自己看，也写给想看的人。

**为什么不做一个功能繁多的编辑器**
截图工具的 90% 使用场景是「截下来发给别人」。为剩下 10% 堆功能，会让那 90% 变慢。

**为什么界面是玻璃的**
因为它常驻。一个常驻的窗口如果是实心色块，就是在你的桌面上永久占一块地。让它透出来，视觉上就退到背景里去了。

**为什么长截图停多久都不结束**
因为你在看内容。让人「必须在 3 秒内决定」是无礼的。

## 技术

| | |
|---|---|
| 语言 | Swift 6 |
| 界面 | SwiftUI + AppKit（`NSHostingView` 混合） |
| 截图 | ScreenCaptureKit · `CGWindowListCreateImage` |
| 录制 | ScreenCaptureKit（`sourceRect` 限定区域） |
| 窗口材质 | `NSGlassEffectView` / `NSVisualEffectView` |
| 打包 | SwiftPM + 自定义 `release.sh`（一条命令发版） |

**1500+ 条自测断言**，涵盖渲染像素、窗口几何、拼接精度、录制排除列表。
发版脚本会校验 bundle 名 / ID / 卷名等不变量，防止发出去的包身份漂移。

更多实现细节见 [`Docs/`](Docs/)。
